# Tennis Market Lab

A research project for modeling professional tennis outcomes
and comparing probabilistic forecasts against prediction-market prices.

## Goals

- Build calibrated ATP/WTA pre-match forecasts
- Implement tennis Elo and surface-specific ratings
- Model live match win probabilities from point/game/set state
- Collect Kalshi prediction-market prices and order books
- Study model-vs-market discrepancies and market efficiency
